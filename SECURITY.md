# Security Policy

## Scope

This repository is a proof of concept and not production infrastructure.

That said, security issues still matter because the repository is meant to illustrate protocol safety boundaries correctly.

## Reporting

Please do not open a public issue for sensitive vulnerability details.

Send security reports to:

- `lancy@tabilabs.org`

Include:

1. affected files or contracts;
2. attack preconditions;
3. impact on protocol restrictions, replay protection, or consumer semantics;
4. reproduction steps when possible.

## Disclosure Expectations

- Public issues are appropriate for non-sensitive bugs, documentation mistakes, or test gaps.
- Private reporting is preferred for anything that could be copy-pasted into a live exploit pattern.
